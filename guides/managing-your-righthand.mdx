Open [Righthands](https://teams.righthand.ai/righthands), select a Righthand, then choose **Manage**. Settings are organized by the part of the Righthand they affect.

| Setting | What it controls |
| --- | --- |
| **Voice** | The voice option used for calls: Female, Male, or Neutral. |
| **Budget** | The Righthand's monthly budget cap. |
| **Conversation Style** | How formally the Righthand speaks to you and to other people. |
| **Communications Policy** | Allow, Ask, or Never for each outbound channel. |
| **Plan** | Starter or Pro subscription and usage capacity. |
| **Model** | The AI model used by the Righthand. |
| **Slack** | The Righthand's Slack bot integration. |
| **GitHub** | The personal access token used for GitHub work. |
| **Retire** | Permanently retire the Righthand. |

## Conversation style

Choose **Formal**, **Casual**, or **Very casual** separately for communication **To you** and **To others**, then select **Save**.

## Model

Model choice is an advanced setting. A different model can change reasoning, latency, and usage. Keep the current selection unless you have a specific workload requirement.

## Retire a Righthand

**Retire** is permanent. Open **Manage → Retire**, type the Righthand's exact name, and select **Retire**. Retirement removes the Righthand from active use and ends its subscription.

<Warning>
  Review or export anything you need before retiring a Righthand. If you only need to control spending, change the plan or budget instead.
</Warning>
