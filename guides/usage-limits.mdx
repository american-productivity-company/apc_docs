Starter and Pro subscriptions are billed monthly per Righthand. Each includes a weekly allowance of working capacity. The platform reports usage as credits and as a percentage of the current weekly allowance.

| Plan | Weekly capacity |
| --- | ---: |
| **Starter** | 1x |
| **Pro** | 4x Starter |

## View usage

Open **Account → Team settings → Usage** or go directly to [Team usage](https://teams.righthand.ai/team-settings?section=usage). Select a Righthand to review credits used each day and how usage compares with the included weekly allowance.

The [billing dashboard](https://teams.righthand.ai/team-settings/billing) also summarizes each Righthand's plan, subscription cost, status, and current usage.

## Weekly reset and notices

The included allowance resets every Sunday at **12:00 UTC**. Righthand sends a text notice when a Righthand reaches:

- **80%** of the weekly allowance
- **95%** of the weekly allowance
- **100%**, when work has to pause

Paused work is picked back up automatically after the weekly reset.

## Add capacity

You have two options when a Righthand is running low:

- **Usage Boost:** a one-time **$39** charge that adds 1x capacity for the rest of the current billing cycle.
- **Plan change:** move from Starter to Pro for 4x ongoing capacity. Plan changes apply immediately and are prorated.

Buy a Usage Boost from the Righthand subscriptions table in the [billing dashboard](https://teams.righthand.ai/team-settings/billing), or [change the Righthand's plan](/guides/plans-and-pricing) from **Manage → Plan**.

<Note>
  A payment method is required for a Usage Boost or paid plan change.
</Note>

## If work pauses unexpectedly

1. Check the Righthand's **Activity** for a usage notice or another blocking question.
2. Review **Team settings → Usage**.
3. Buy a Usage Boost or change the plan if more capacity is needed before Sunday.
4. If usage does not explain the pause, contact [support@humans.righthand.ai](mailto:support@humans.righthand.ai).
