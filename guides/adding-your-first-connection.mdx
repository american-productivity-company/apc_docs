Connections let Righthands use accounts and services such as Google Workspace, HubSpot, GitHub, and many others. Adding a connection and granting access are separate steps: successful sign-in does not automatically give every Righthand access.

## Add a connection

<Steps>
  <Step title="Open Connections">
    Go to [Connections](https://teams.righthand.ai/connections).
  </Step>
  <Step title="Choose Add">
    Select the **Add** row. Search the catalog for the service you want to connect.
  </Step>
  <Step title="Sign in to the service">
    Select the service and complete its authorization flow. Check the account name before approving access so you do not connect the wrong personal or company account.
  </Step>
  <Step title="Open the new connection">
    After authorization, Righthand returns to **Connections** with the new connection selected. Give it a recognizable name if needed.
  </Step>
  <Step title="Set scope and Righthand access">
    Choose whether the connection is **Personal**, **Righthand**, or **Team**. Then select the Righthands that should have access.
  </Step>
  <Step title="Review tool permissions">
    If the connection exposes configurable tools, set each tool to **Yes**, **Ask**, or **No**.
  </Step>
</Steps>

<Warning>
  Grant only the account, repositories, workspaces, and tool permissions the Righthand needs. A broad provider authorization and a broad Righthand permission are separate decisions; review both.
</Warning>

## Verify the connection

Ask the assigned Righthand to perform a small, reversible read action, such as listing a folder or finding a known record. Confirm the result in **Activity** before relying on the connection for a larger workflow.

If a connection has a red status mark or returns an authorization error, open it and reconnect the underlying account. If that fails, delete the broken connection and add it again.
