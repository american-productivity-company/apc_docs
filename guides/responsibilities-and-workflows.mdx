Responsibilities describe ongoing work a Righthand owns. A responsibility can include a charter, reusable skills, and scheduled routines so the Righthand has both the goal and the operating instructions needed to carry it out.

## Assign responsibilities while hiring

The hire flow begins with **Own**. Select one or more responsibilities, or choose **Decide later**. After choosing a profile and hiring, Righthand assigns the selected responsibility packs while the new Righthand is being set up.

## Manage an existing Righthand's responsibilities

1. Open [Righthands](https://teams.righthand.ai/righthands).
2. Select the Righthand.
3. Open **Responsibilities**.
4. Review the responsibilities already assigned and add or remove work as needed.

Responsibility adoption may show as pending while the Righthand reads the charter and sets up its work. Follow the Righthand's **Activity** for progress or questions.

## Review workflows

Workflow activity records recurring or multi-step work. Use it to answer:

- Which Righthand owns the run?
- Is it scheduled, running, paused, complete, or failed?
- Which event or tool action happened last?
- Did the Righthand ask for a decision or approval?

Open a workflow run to inspect its event history and any reported error. Pausing a workflow stops future work from continuing until it is resumed; it does not undo actions that already happened.

<Tip>
  Keep responsibility language outcome-focused. “Send a concise pipeline report every Monday” is clearer than “help with sales.” Add source locations, recipients, timing, and approval boundaries.
</Tip>
