By default, Righthands use a Righthand-managed email domain. Team administrators can verify a custom domain for branded Righthand email addresses.

## Use a subdomain

Use a dedicated subdomain such as `ai.yourcompany.com` instead of your company's primary email domain. Custom email setup can require MX and other DNS records; changing records on the primary domain can interrupt existing company email.

<Warning>
  Make DNS changes with the person who manages your company's email. Copy the records Righthand generates for your domain—do not reuse record values from another team or from a screenshot.
</Warning>

## Add and verify the domain

<Steps>
  <Step title="Open Domains">
    Open the **Account** menu, select **Team settings**, then select **Domains**. Or go directly to [Team domains](https://teams.righthand.ai/team-settings?section=domains).
  </Step>
  <Step title="Add the subdomain">
    Select the **Add** row, enter the complete subdomain—for example, `ai.yourcompany.com`—and select **Add**.
  </Step>
  <Step title="Open the pending domain">
    Select the domain from the list. Righthand shows the DNS records generated for this exact domain.
  </Step>
  <Step title="Create the DNS records">
    In your DNS provider, add every record Righthand lists. Match the record type, host or name, value, and priority exactly. The number and type of records can vary, so use the live values rather than expecting a fixed set.
  </Step>
  <Step title="Verify">
    Return to Righthand and select **Verify**. If DNS has not propagated yet, wait and try again later.
  </Step>
</Steps>

After verification, the domain is available to the team's Righthands. Keep the verification records in DNS while the domain is in use.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Verification is still pending">
    Confirm that every record matches the values for this domain, including punctuation and MX priority. DNS propagation time varies by provider. Wait for the provider's current TTL, then select **Verify** again.
  </Accordion>
  <Accordion title="My DNS provider uses different field names">
    “Host” and “Name” commonly refer to the same field; “Value,” “Target,” and “Points to” commonly refer to the destination. Follow your provider's documentation and do not add your domain twice if the provider appends it automatically.
  </Accordion>
  <Accordion title="The record host is not visible or is ambiguous">
    Stop before changing DNS and contact support with the domain name. Do not guess on a production email domain.
  </Accordion>
</AccordionGroup>

## Remove a domain

Open **Team settings → Domains**, select the domain, and choose **Delete**. Remove the DNS records only after confirming no Righthand still depends on that domain.
