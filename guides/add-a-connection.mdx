Every connection can have up to three layers of control: **scope**, **Righthand access**, and **tool permissions**.

## 1. Scope

Scope controls who owns the connection and who can grant access.

| Scope | Use it for | Who can manage access |
| --- | --- | --- |
| **Personal** | An account that belongs to one human team member | The creator or a team administrator |
| **Righthand** | An account dedicated to one Righthand | The selected Righthand is assigned automatically |
| **Team** | An account the team intentionally shares | Authorized team members can assign Righthands |

Only the connection creator or a team administrator can change scope. Choosing **Righthand** also requires selecting which Righthand owns the connection.

## 2. Righthand access

The Righthand selector determines which assistants can use the connection.

- Team connections can be assigned to multiple Righthands.
- The creator can assign their own Personal connection.
- A Personal connection created by someone else is read-only to you.
- A Righthand-scoped connection belongs to its selected Righthand.

Removing a Righthand from the selector disables that Righthand's access without deleting the underlying connection.

## 3. Tool permissions

Connections that expose configurable tools use three values:

| Permission | Behavior |
| --- | --- |
| **Yes** | The Righthand may use the tool without asking first. |
| **Ask** | The Righthand must receive approval before using the tool. |
| **No** | The Righthand may not use the tool. |

Use the top permission row to apply one value to every tool, or expand **Tools** to configure them individually. For example, you can allow email search while requiring approval to send an email.

<Note>
  Tool permission and [communications policy](/security/external-communications) are separate controls. An outward action must satisfy both the connection's tool permission and the Righthand's policy for that communications channel.
</Note>

## Manage or remove a connection

Open [Connections](https://teams.righthand.ai/connections) and select the connection. From its detail pane you can:

- Rename it.
- Change Righthand access.
- Change tool permissions.
- Change scope when authorized.
- Delete the connection.

Deleting a connection removes it from Righthand. If you need to revoke access at the provider too, revoke the corresponding authorization or token in that provider's security settings.
