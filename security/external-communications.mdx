Each Righthand has a **Communications Policy** for externally visible outbound actions. Configure it separately for **Email**, **Messages**, **Calls**, **Slack**, **Calendar**, and **Connected apps**.

## Configure the policy

1. Open [Righthands](https://teams.righthand.ai/righthands) and select a Righthand.
2. Select **Manage**.
3. Select **Communications Policy**.
4. Set **All channels** at once or choose a different value for each channel.

Changes save automatically. Wait for the **Saved** confirmation before leaving the page.

## Allow, Ask, and Never

| Policy | External outbound behavior |
| --- | --- |
| **Allow** | The Righthand may perform outward actions on that channel without asking first. |
| **Ask** | The Righthand needs an explicit outward instruction or conversational approval for the recipient and action. |
| **Never** | External outbound actions on that channel are blocked. |

Examples of outward actions include sending email or SMS, making an outbound call, posting or reacting in Slack, sending a calendar invitation or attendee update, and using a connected app in a way another person can see.

Reading, summarizing, or drafting in response to inbound communication is not itself an outbound action. Sending the draft is.

## How Ask works

**Ask** is conversational. You approve in your normal conversation with the Righthand; there is no separate approval dashboard.

An explicit instruction can authorize the action:

> Email Priya the revised proposal and ask her to confirm by Friday.

A general task does not authorize contact merely because contact might help:

> Finish the proposal by Friday.

The Righthand must ask before emailing Priya in the second example. Silence, urgency, and a past approval do not create new permission.

You can also give bounded standing permission, such as “coordinate directly with the venue about this event.” Material changes to the recipient, audience, commitment, price, timing, or meaning require fresh approval.

## Team-internal communication

Ask and Never govern communication outside the APC team. Authenticated users and Righthands on the same team remain reachable.

A person is not team-internal merely because a contact file calls them a coworker, manager, client, friend, or other known contact. Mixed audiences count as external when any recipient is outside the team.

<Warning>
  Communications Policy and connection tool permissions are both enforced. Setting a channel to Allow does not override a connection tool set to Ask or No.
</Warning>

## Suggested starting point

- Use **Ask** for email, messages, calls, calendar, and connected apps while you learn how the Righthand works.
- Use **Allow** only where autonomous outward action is expected and appropriately scoped.
- Use **Never** where the Righthand should read or draft but must not create an external effect.

Review the Righthand's Activity after policy changes to confirm the behavior matches your intent.
